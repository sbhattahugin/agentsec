# Targets

Put one YAML file per agent you want AgentSec to test here (subfolders are fine).
The web console (`agentsec ui` / `python demo/console.py`) lists every `*.yaml` in this folder.

```yaml
target:
  name: my-agent
  environment: test
  resetEndpoint: https://my-agent-test/admin/reset   # optional, POSTed before each scan
agent:
  endpoint: https://my-agent-test/api/chat           # POST {message, documents, sessionId}
connections:
  - type: mcp
    endpoint: https://my-mcp-test
    telemetry: https://my-mcp-test/telemetry          # GET ?testId=... -> {events: [...]}
security:
  authentication: oauth2
  identity:
    client_id: my-agent-sp
    token_endpoint: https://login.example.com/oauth/token
    introspection_endpoint: https://login.example.com/oauth/introspect
    client_secret_env: AGENTSEC_CLIENT_SECRET
testData:                                             # optional, used by some attacks
  sampleId: X-1001
  idRange: [X-1000, X-1099]
```

`targets/lab/` is generated by `demo/lab.py` (the dummy agents) and is not committed.
Only point AgentSec at **test** environments: it really attacks the agent.
